## Disagreements between documents (explicit list)

1. Storage: SQLite (Proposal, System Design) vs Postgres (ADR 0005, compose, README).
2. Money type: Decimal vs integer minor units.
3. Tier model: 4 tiers (T0-T3) vs 3 tiers vs the task's T0-T4.
4. Who ranks: "decision model" (Proposal) vs "engine only" (ADR 0003, Strategy Agent 4).
5. Scenario canon: Rina (edgecase, Strategy "golden Rina") vs the proposal's worked example; both claim to be "the" example.
6. Dates: day offsets vs calendar dates.
7. Competition rules: Proposal's reading of the PDF vs the website (see row 16).
8. Rina's printed lows for options B and C vs recomputation.

## Items in the repo that would mislead a reader

- The README badge and tech-stack table present LangGraph as settled, `docs/agent.md` says pause points are "LangGraph interrupts". If ADR 0006's gate chooses plain code, those lines must change.
- `docs/checkpoint.md` says "no AI provider wired in yet" while the System Design prices an AI provider; both are right (design vs code).
