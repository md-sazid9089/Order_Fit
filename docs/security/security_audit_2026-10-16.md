# OrderFit security audit and hardening — 16 October 2026

> Historical snapshot. The [17 October continuation](security_audit_2026-10-17.md)
> reconciles teammate changes, supersedes open CSP/session/pagination status, and
> records new admin findings, fixes, migration and current verification limits.

Scope: working tree on `main`, starting HEAD `6ca0ec3`. Existing preparation and frontend
changes were preserved. Review assumes hostile tenants, hostile uploaded documents and hostile
networks. Execution used synthetic data, local processes and labeled, uniquely named disposable
PostgreSQL 17 containers with separate migrator/API/worker logins. No hosted database, provider,
email, bank or lender was contacted. Advisory/package registries and public action repositories
were queried. No credentials, document contents or matched secret values were printed.

This is a source review plus regression testing, not a production certification or exhaustive
dynamic proof of every SQL statement. The [route inventory](route_inventory.md) records all
106 API handlers, in addition to the two probes in `backend/orderfit/api/main.py:333`.

## Unverified and rotation handoff

- Rotate the remote database credentials historically stored in `.env` and `backend/.env`
  (`DATABASE_URL`, `DATABASE_URL_DIRECT`), especially owner credentials, unless independently
  verified already rotated. Inspect deployment copies/backups separately. No newly confirmed
  OpenAI/S3/session/fingerprint-key exposure was found by the scoped pattern scan; absence of a
  match is not proof of absence. Git history was not rewritten.
- No hosted Neon/PgBouncer runtime role, TLS handshake, Render worker, S3 bucket policy/KMS,
  encryption-at-rest, backup/retention or restore test was performed. Stricter startup settings
  must be applied to the real deployment before using this code there; supply a trusted CA
  through sslrootcert=system or an explicit CA file. Do not revert to sslmode=require to boot.
- No live OpenAI quality/injection evaluation, provider retention verification, browser hostile
  network test, distributed/load test, OS/container-image CVE scan or CI-host execution was run.
- Outstanding design work: MFA and verified-email registration; privilege-change session epoch;
  isolated auth DB credentials; strict script CSP compatible with the current renderer; edge
  quotas/readiness admission; documented encrypted retention/restore and external audit anchoring.
  The current code remains sandbox-only. These are not satisfied by passing local tests.
